# 성적 CSV 검증 프로그램

## ① 무엇을 하나요 (What)

성적 CSV 파일을 읽어 이름과 점수가 명세에 맞는 데이터만 남기고, 잘못된 행은 건너뛴 이유와 함께 기록합니다.

## ② 왜 만들었나요 (Why)

CSV 파일에는 점수 누락, 범위 밖 점수, 잘못된 형식 등의 문제가 포함될 수 있다. 이러한 데이터를 구분하여 잘못된 성적 처리를 방지하고, 제외한 이유를 확인할 수 있도록 만들었다

## ③ 어떻게 쓰나요 (How)

Python이 설치된 환경에서 프로젝트 폴더로 이동한 뒤 필요한 패키지를 설치합니다.

```bash
python -m pip install pytest pytest-cov
```

CSV 파일을 직접 읽어 결과를 확인하려면 다음 명령을 실행합니다.

```bash
python load_scores.py scores.csv
```

## ④ 어떻게 테스트하나요

전체 테스트 실행:

```bash
python -m pytest -q
```

커버리지 확인:

```bash
python -m pytest --cov=load_scores --cov-report=term-missing
```

테스트를 실행한 결과 9 passed
커버리지 80%
미실행 구간 77~86행

## ⑤ 파일 구성

| 파일 | 하는 일 |
| --- | --- |
| `load_scores.py` | 성적 CSV를 읽고 유효 데이터와 건너뛴 행을 반환합니다. |
| `scores.csv` | 일반 성적 데이터와 여러 오류 사례가 들어 있는 입력 파일입니다. |
| `empty.csv` | 헤더만 있는 CSV 파일입니다. |
| `weird.csv` | 이름·점수 누락, 범위 밖 점수 등 비정상 데이터가 들어 있습니다. |
| `test_load_scores.py` | 정상·예외·경계값을 확인하는 pytest 테스트입니다. |
| `test_ai_A.py` | 코드만 제공한 AI 테스트 결과를 저장하는 파일입니다. |
| `test_ai_B.py` | 명세만 제공한 AI 테스트 결과를 저장하는 파일입니다. |
| `bug3_logic.py` | 논리 오류가 포함된 예제 코드입니다. |
| `prompts.txt` | AI 비교 실험에 사용할 프롬프트 원문입니다. |
